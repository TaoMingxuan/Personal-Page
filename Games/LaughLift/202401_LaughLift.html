📖 项目简介

Laugh Lift 是 Global Game Jam 2024 参赛作品，一款围绕主题「Laugh」设计的休闲点击游戏。玩家需要精准点击不断移动中的角色，使角色持续向上攀升；每次成功点击都会产生一次随机方向的上升，并播放角色独特的笑声。

🎯 核心体验：精准点击、随机上升、角色笑声反馈、无限上升、挑战最高分与收集笑声。

🛠 设计过程

从 Game Jam 主题到核心玩法

本次 Game Jam 的主题为「Laugh」。我首先将主题拆解为“让玩家笑”和“笑声本身”两个方向，并发现两者可以结合：如果笑声具有感染力，那么游戏就可以通过持续制造笑声来让玩家发笑。

因此，我反向寻找一种能够高频触发笑声的交互方式，最终确定“精准点击角色”作为核心交互。每次成功点击都会让角色随机向左上或右上方向移动，同时触发该角色独特的笑声，从而形成「Click → Lift → Laugh」的核心循环。

72小时开发范围取舍（Scope Management）

确定核心玩法后，我通过快速脑测判断哪些内容会强化核心体验，哪些内容反而可能分散玩家注意力：

  • 必须做：精准点击、随机移动、笑声反馈、死亡/重开、分数与核心流程。
  • 应该做：角色切换、笑声解锁、不同高度环境、无限背景与摄像机跟随。
  • 可以做：更多角色、更多笑声及更多环境内容。
  • 主动削减：区域专属障碍物、辅助道具等系统。因为玩家已经需要精准追踪随机移动的角色，继续增加目标可能削弱“点击触发笑声”这一核心体验。

摄像机迭代

开发过程中发现角色随机移动配合直接跟随摄像机会造成过快的背景运动，使角色难以观察，并可能带来视觉眩晕。因此加入延迟跟随机制：只有当角色超过屏幕中部区域后，摄像机才开始跟随。

无限背景实现

无限背景是我在本项目中最满意的技术实现之一。远景背景本身不直接移动，中景使用两个相同背景区域进行无缝衔接，并根据摄像机 Z 轴位置与公式计算其位置，使玩家能够持续向上移动而不产生明显的场景边界。

不同高度还会切换海底、水下、农场、城市、天空与太空等环境，使无限上升拥有明确的视觉进度。这套实现也成为我之后项目处理类似无限场景需求时的技术参考。

🧪 试玩与反馈

项目最后一天上午进行了跨团队测试。测试中最直接的反馈是玩家确实会因为角色不断产生的笑声而笑出来，验证了最初“通过笑声让玩家发笑”的主题假设。

但测试同时暴露出游戏性的限制：由于核心玩法非常简单，玩家很快能够理解完整规则，大多数测试者体验约 3 次后便离开。项目缺乏局外成长、敌人、陷阱、辅助道具等能够支撑长期重复游玩的系统。

这并不是单纯的“内容没有做够”，而是与项目最初的设计目标存在矛盾：如果为了增加游戏深度加入过多系统，也可能削弱游戏围绕「Laugh」建立的核心体验。

📌 设计反思

我并不认为 Laugh Lift 是一个玩法深度很高的项目，但它让我形成了一个重要的 Game Jam 设计判断：在处理抽象主题时，主题契合度可以优先于传统意义上的玩法复杂度。

对于普通商业项目，我可能会更关注成长、策略、内容量与长期留存；但在 Game Jam 中，首先需要回答的是：“为什么这个游戏一定要是这个主题？”

Laugh Lift 的答案非常直接：因为玩家每一次点击，都在通过笑声让角色继续上升。

🏆 项目总结

Laugh Lift 在 72 小时内完成从抽象主题、核心机制、可玩原型到完整展示版本的开发，并在 Global Game Jam 2024 Teesside 站点的 20+ 个作品中排名第 4。

这个项目让我重点提升了两项能力：

  • Rapid Prototyping：能够在短时间内从抽象主题快速形成可验证的核心玩法。
  • Scope Management：能够通过快速脑测判断哪些功能必须做、应该做、可以做，以及哪些内容即使能够实现也不应该加入。
  • Theme-driven Design：在 Game Jam 环境下优先保证玩法与主题之间的直接联系，而不是为了增加复杂度而堆叠系统。
  • 技术积累：完成无限背景与摄像机跟随等系统，并将经验迁移到后续项目。
